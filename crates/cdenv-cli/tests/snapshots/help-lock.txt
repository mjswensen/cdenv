Create or update a workspace Feature lockfile

Usage: cdenv lock [OPTIONS] <NAME>

Arguments:
  <NAME>  The workspace whose Feature lockfile will be updated

Options:
      --config <PATH>         A repository-relative configuration selecting the adjacent lockfile
      --root <PATH>           Use a specific cdenv root instead of environment or home-directory defaults
      --modify-ssh-config     Allow cdenv to add its Include directive to the user SSH config
      --no-modify-ssh-config  Record that cdenv must not modify the user SSH config
  -h, --help                  Print help
